# CookieMute — Privacy & Support

CookieMute is a Chrome extension that automatically rejects cookie consent banners.

- **Privacy policy:** [PRIVACY.md](PRIVACY.md)
- **Support and bug reports:** [Issues](https://github.com/chenbin2015/cookiemute-support/issues)
- **Chrome Web Store:** listing will be linked here after review

CookieMute runs entirely in your browser. It makes no network requests, collects no data, and stores its settings only in local extension storage.

## Support

See [SUPPORT.md](SUPPORT.md) for what to include when reporting a site that was not handled correctly.

This repository hosts only the public policy and support pages. It does not contain the extension source code.
